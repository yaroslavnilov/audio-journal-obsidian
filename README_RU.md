# Audio Journal to Obsidian (Whisper + Ollama)

> 🌐 *[English version](README.md)*

Автоматизированный, **на 100% локальный и приватный** пайплайн, который превращает несколько голосовых заметок за день в единую структурированную, отредактированную и красиво оформленную дневниковую запись в формате **Obsidian Markdown**.

---

## ✨ Возможности

* **🔒 100% локально и приватно:** Ваши личные мысли и аудиофайлы никогда не покидают ваше устройство.
* **🎙️ Быстрое локальное распознавание речи:** Работает на базе `faster-whisper` (`medium` / CPU `int8`) для эффективного и легкого транскрибирования.
* **🧠 Умная AI-редактура:** Использует локальную LLM через `Ollama` для удаления слов-паразитов и запинок, исправления грамматики, хронологической группировки заметок по тематическим главам и автоматической расстановки `[[вики-ссылок]]`.
* **📅 Заметки с привязкой к дате:** Автоматически создает аккуратные дневные файлы формата `YYYY-MM-DD_daily_journal.md`, не перезаписывая предыдущие записи.
* **📝 Сохранение сырого текста:** Сохраняет неотредактированный объединенный транскрипт (`YYYY-MM-DD_raw_combined.txt`) для отладки и справки.

---

## 🛠 Стек технологий

* **[faster-whisper](https://github.com/SYSTRAN/faster-whisper)** — Быстрый локальный движок транскрибации аудио.
* **[Ollama](https://ollama.com/)** + **[OpenAI Python SDK](https://github.com/openai/openai-python)** — Интеграция с локальными LLM для редактирования и форматирования.

## 🚀 Быстрый старт

### 1. Требования

* **Python 3.9+**
* Запущенный экземпляр **Ollama** с установленной моделью (например, `qwen2.5:14b`, `llama3.1` и т. д.):
  ```bash
  ollama run qwen2.5:14b
  ```

### 2. Установка

Клонируйте репозиторий и настройте окружение:

```bash
git clone https://github.com/yaroslavnilov/audio-journal-obsidian.git
cd audio-journal-obsidian

# Создание виртуального окружения
python -m venv venv

# Активация виртуального окружения
# На Windows:
venv\Scripts\activate
# На Linux/macOS:
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### 3. Использование

1. Поместите ваши голосовые заметки (`.mp3`, `.wav`, `.m4a`, `.flac`, `.ogg`) в папку `audio_input/`.
2. Запустите скрипт обработки:
   ```bash
   python main.py
   ```
3. Готовая запись появится в `processed_text/YYYY-MM-DD_daily_journal.md`.
